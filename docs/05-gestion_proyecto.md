# Gestión de proyecto

**Tablero Trello:** https://trello.com/b/nx4n3etX/estructura-de-datos-grupo-6
**Columnas:** Backlog, En progreso, En revisión, Hecho.

**Metodología:** Scrum simplificado. Un sprint por cada TP (TP0 a TP10). Cada
etapa es una tarjeta con checklist que se mueve de columna a medida que avanza.
Al cerrar cada sprint, el grupo hace una retro breve: qué salió bien, qué no y
qué se cambia.

**Historia de usuario de ejemplo:**
"Como padre quiero buscar un videojuego por título para ver su clasificación de edad."
Criterios de aceptación: la búsqueda no distingue mayúsculas de minúsculas; si el
juego no existe, el sistema lo informa.
